# R&W skill rules

One short passage per item. Stem language should match real Digital SAT phrasing.

## WIC — Words in Context

- Blank or underlined word. Four real words/phrases of similar register.
- Context must force **one** sense. Distractors = plausible wrong senses from nearby cues, not rarity.
- Ban dictionary-definition options (“means X”).
- **Substitution matrix (required).** Write all four options into the blank and record what each does to the sentence. Any two that both read acceptably = dead item, regardless of which is “better.” Options match part of speech, register, and collocation.

## TSP — Text Structure and Purpose

- Ask what a **span** or the text is doing (function), not a vibe.
- Key is the rhetorical job, not a content summary.

## CTC — Cross-Text Connections

- Two labeled texts. Both must be necessary.
- Ask a relation (agree / disagree / extend / qualify). The relation must not be reversible unless that is the question.
- For each distractor, quote its strongest supporting span and why the asked relation still fails.

## CID — Central Ideas and Details

- Key is stated or tightly entailed. Ban “reasonable inference” as the CID key (that is INF).

## COE — Command of Evidence

- Textual: which detail supports a claim already on the table.
- Quantitative: table/graph is required; key comes from the data; prose matches the display.

## INF — Inferences

- Must follow from the passage. Fail if it needs world knowledge or a leap.
- Distractors: true-in-the-world but unsupported; opposite; too strong.

## BOU — Boundaries

- Punctuation / clause boundaries. Parse every option as a full sentence.
- Exactly one grammatical reading. Watch comma splice vs appositive vs nonrestrictive clause.
- **One axis.** All four options are the same words in the same order, differing only in punctuation/boundary marks. No option may introduce a second, untested error.

## FSS — Form, Structure, and Sense

- Agreement, tense, pronoun, modifier, comparison, verb form.
- Exactly one option satisfies the grammar. Another tense that also works = fail.
- **One axis.** Same words, same order; only the tested inflected form changes. A second untested error makes the item unfair.

## TRA — Transitions

- Logical relation between the flanking sentences (contrast, cause, example, addition).
- Test all four connectors in the blank. Only one fits.
- Four **distinct logical classes**, one per option (e.g. contrast / cause / exemplification / addition). Two options from the same class is a two-key item even if one is “smoother.”
- The relation must be recoverable from the flanking sentences with the connector removed.

## SYN — Rhetorical Synthesis

- Notes + a student goal. Every content claim in the key must appear in the notes.
- Ban invented facts. Key meets **all** stated goals; no distractor meets all of them.
- Notes are bullet fragments, not prose, and must contain the bait each distractor overreaches from.
- The key must not be the only option that reuses the goal sentence’s wording.
